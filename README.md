# Lite Cgrft

Um protótipo simples inspirado em Minecraft, feito com HTML + CSS + JavaScript puro.

## Como rodar

1. Entre na pasta do projeto.
2. Rode um servidor local (exemplo com Python):

```bash
python3 -m http.server 8000
```

3. Abra `http://localhost:8000` no navegador.

## Controles

- **WASD**: mover personagem.
- **Clique esquerdo**: quebrar bloco.
- **Clique direito**: colocar bloco.
- **Teclas 1 a 5**: trocar bloco selecionado.

## O que já existe

- Mundo em blocos com geração de terreno.
- Árvores simples geradas aleatoriamente.
- Inventário básico com coleta e gasto de blocos.
- Barra rápida (hotbar) para selecionar blocos.
